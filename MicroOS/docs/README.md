## Ноты

[docs/ноты/](ноты/README.md) содержит итоговые документы, которыми фиксируются принятые решения и закрытие этапов. Нота может быть историческим срезом: при расхождении с более новым паспортом дата и статус документа обязательны для интерпретации.

## История

[docs/история/](история/README.md) содержит прежние архитектурные документы, дорожные карты и контракты. Они сохранены для прослеживаемости решений, но не являются актуальным руководством по эксплуатации.

## Правила пополнения

1. Новый действующий контракт размещается в корне `docs/` и связывается с ПАСПОРТОМ.
2. Итоговая нота закрытия размещается в `docs/ноты/`.
3. Устаревший, но полезный для истории документ переносится или копируется в `docs/история/` с явной маркировкой.
4. Рабочая переписка, временные mock-результаты и секретные снимки не публикуются как действующее руководство.
5. При обновлении документации не изменяются исходники и бинарники.
6. Каждый документ содержит дату и, где применимо, опорный коммит или версию.

## 1. Реестр событий шины (core/Events.h)

Диапазоны: `0x0000–0x00FF` ядро · `0x0100+` сервисы · `0x0200+` транспорт · `0x0300+` драйверы · `0x0400+` домен · `0x0900+` команды · `0x1000+` приложения профилей.

| ID | Событие | Назначение |
|---|---|---|
| `0x0000` | `SH_EVENT_BOOT` | система загрузилась (payload: причина) |
| `0x0001` | `SH_EVENT_READY` | все модули start() завершили |
| `0x0002` | `SH_EVENT_SHUTDOWN` | штатное завершение перед ребутом |
| `0x0003` | `SH_EVENT_MODULE_STATUS` | модуль сменил состояние (code: 1=init,2=start,3=stop,4=error) |
| `0x0004` | `SH_EVENT_SAFE_MODE_ENTERED` | вход в Kernel Safe Mode (code: причина, см. Kernel::SafeModeReason) |
| `0x0005` | `SH_EVENT_BOOTLOOP_DETECTED` | bootloop-счётчик достиг порога |
| `0x0006` | `SH_EVENT_EVENT_OVERFLOW` | очередь шины переполнена (code: число потерянных событий) |
| `0x0007` | `SH_EVENT_TICK_OVERRUN` | модуль превысил бюджет tick (code: длительность, мс) |
| `0x0008` | `SH_EVENT_DEGRADED_LEVEL` | смена уровня деградации (code: 0=FULL,1=LOCAL_NET,2=AUTONOMOUS) |
| `0x0100` | `CFG_EVENT_CHANGED` | параметр изменён (payload: ключ) |
| `0x0101` | `CFG_EVENT_SAVE_FAILED` | ошибка записи конфигурации |
| `0x0102` | `CFG_EVENT_MIGRATED` | выполнена миграция NVS v2.5.0→5.0 |
| `0x0110` | `STORAGE_EVENT_LOW_SPACE` | свободно < порога (code: % заполнения) |
| `0x0111` | `STORAGE_EVENT_CORRUPTED` | файл повреждён (payload: путь) |
| `0x0120` | `TIME_EVENT_SYNCED` | время синхронизировано (RTC или NTP) |
| `0x0121` | `TIME_EVENT_RTC_LOST` | DS3231 перестал отвечать |
| `0x0122` | `TIME_EVENT_RTC_RESTORED` | DS3231 восстановлен после recovery |
| `0x0130` | `AUTH_EVENT_LOGIN` | успешная авторизация (code: роль) |
| `0x0131` | `AUTH_EVENT_LOGIN_FAILED` | неудачная попытка (code: осталось попыток) |
| `0x0132` | `AUTH_EVENT_LOCKED_OUT` | блокировка после N попыток (code: длительность, сек) |
| `0x0133` | `AUTH_EVENT_SETUP_REQUIRED` | C1: первый старт, ПИН не задан — требуется provisioning |
| `0x0140` | `HEALTH_EVENT_WARNING` | проверка дала WARNING |
| `0x0141` | `HEALTH_EVENT_CRITICAL` | проверка дала CRITICAL |
| `0x0142` | `HEALTH_EVENT_RECOVERED` | проверка вернулась в норму |
| `0x0143` | `HEALTH_EVENT_WDT_REBOOT` | планируется ребут по WDT/ПАЗ |
| `0x0150` | `OTA_EVENT_STARTED` | началось обновление |
| `0x0151` | `OTA_EVENT_PROGRESS` | прогресс (code: %) |
| `0x0152` | `OTA_EVENT_SUCCESS` | прошивка записана, ребут |
| `0x0153` | `OTA_EVENT_FAILED` | ошибка (code: причина) |
| `0x0154` | `OTA_EVENT_ROLLBACK` | авто-откат на предыдущий раздел |
| `0x0160` | `TEL_EVENT_SNAPSHOT` | снимок метрик собран (code: heap КБ; payload: кратко) |
| `0x0170` | `SND_EVENT_STARTED` | фраза началась (payload: имя) |
| `0x0170` | `SCHED_EVENT_PERIOD_CHANGED` | вступил/вышел период (code: 0=день,1=ночь и т.п. по правилу; payload: имя правила) |
| `0x0171` | `SND_EVENT_FINISHED` | фраза доиграла (payload: имя) |
| `0x0172` | `SND_EVENT_DROPPED` | фраза отброшена (очередь полна / тихие часы; payload: имя) |
| `0x0173` | `SND_EVENT_ALARM_ON` | зацикленная сирена включена |
| `0x0174` | `SND_EVENT_ALARM_OFF` | сирена снята |
| `0x0175` | `SND_EVENT_RESUMED` | software-resume после ADVERT |
| `0x0200` | `NET_EVENT_CONNECTED` | link поднят, IP получен |
| `0x0201` | `NET_EVENT_DISCONNECTED` | link потерян |
| `0x0202` | `NET_EVENT_IP_CHANGED` | сменился IP (payload: "x.x.x.x") |
| `0x0203` | `NET_EVENT_GATEWAY_LOST` | шлюз не пингуется |
| `0x0204` | `NET_EVENT_GATEWAY_RESTORED` | шлюз снова доступен |
| `0x0205` | `NET_EVENT_DISABLED` | сеть отключена (джампер/локальный режим) |
| `0x0210` | `SH_EVENT_MQTT_CONNECTED` | подключились к брокеру |
| `0x0211` | `SH_EVENT_MQTT_DISCONNECTED` | потеряли брокера |
| `0x0212` | `SH_EVENT_MQTT_MESSAGE` | входящее сообщение (payload: топик) |
| `0x0220` | `HTTP_EVENT_REQUEST` | входящий запрос (code: число открытых) |
| `0x0300` | `DRV_EVENT_TEMP_UPDATE` | code: температура x10 (°C) |
| `0x0301` | `DRV_EVENT_TEMP_WARNING` | выше порога предупреждения |
| `0x0302` | `DRV_EVENT_TEMP_CRITICAL` | выше критического порога |
| `0x0310` | `DRV_EVENT_WIEGAND_CARD` | карта считана (payload: HEX 8 симв.) |
| `0x0311` | `DRV_EVENT_WIEGAND_NOISE` | битовый мусор отклонён (code: биты) |
| `0x0320` | `DRV_EVENT_AUDIO_STARTED` | начало трека (code: номер) |
| `0x0321` | `DRV_EVENT_AUDIO_FINISHED` | конец трека (BUSY -> HIGH) |
| `0x0322` | `DRV_EVENT_AUDIO_OFFLINE` | плеер не отвечает |
| `0x0323` | `DRV_EVENT_AUDIO_RESTORED` | плеер вернулся |
| `0x0330` | `DRV_EVENT_BUS_RECOVERED` | шина восстановлена (code: номер) |
| `0x0331` | `DRV_EVENT_BUS_DEAD` | recovery не удался |
| `0x0400` | `ACCESS_EVENT_GRANTED` | доступ разрешён (payload: карта) |
| `0x0401` | `ACCESS_EVENT_DENIED` | отказ (code: причина) |
| `0x0402` | `ACCESS_EVENT_LOCKED` | замок закрыт |
| `0x0403` | `ACCESS_EVENT_UNLOCKED` | замок открыт (code: источник) |
| `0x0900` | `SH_EVENT_CMD_EXECUTE` | выполнить команду |
| `0x0901` | `SH_EVENT_CMD_RESPONSE` | ответ на команду |

## 5. Топологию MQTT (MqttTransport, E2)

Префикс `mqtt.prefix` (умолчание `microos`), `<id>` — MAC ETH.

| Топик | Направление | Назначение |
|---|---|---|
| `<pfx>/<id>/state` | publish (retain, LWT) | online/offline |
| `<pfx>/<id>/telemetry` | publish (retain) | JSON-снимок B1 |
| `<pfx>/<id>/events/<NAME>` | publish | зеркало событий шины |
| `<pfx>/<id>/cmd/<verb>` | subscribe | команды: reboot, state, set, ota |
| `<pfx>/all/cmd/<verb>` | subscribe | broadcast-команды |
| `<pfx>/+/events/#` | subscribe | события других устройств -> шина |

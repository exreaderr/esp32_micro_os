# МикроОС 5.8.5 + home_master 0.6.0 — M3.3 BackupAggregator

**Дата:** 04.09.2026 · **Доставка:** исходниками (правило 04.09), структура
папок = репозиторий, копировать поверх клона.

## Что в пакете

### Ядро 5.8.4 → 5.8.5 (4 файла + Version.h)
- **`/api/config/export`** (GET, admin) — ПОЛНЫЙ снимок конфига, включая
  секреты (решение владельца 04.09.2026). `ConfigService::exportSnapshotJson`.
- **`/api/config/import`** (POST, admin) — применить снимок из тела,
  атомарное сохранение, ребут через 1,5 с. Парсер вынесен в
  `applySnapshotJson()` — тот же код, что у restoreFromNvs (единая семантика).
- **MQTT**: `CFG_EVENT_CHANGED` теперь зеркалится как `events/CFG_CHANGED`
  (триггер внепланового снимка; payload — ключ поля).
- Обратная совместимость: замок и шлюз собираются на 5.8.5 без правок
  (контрольные сборки зелёные: lock 1096450 Б, gate 1082278 Б).

### home_master 0.5.2 → 0.6.0 (9 файлов + панель)
- **BackupService** (новый модуль 0x1107): цикл съёма по хостам из
  `bk.hosts` — login → export → SD `/backup/<ip>/config-YYYYMMDD-HHMMSS.json`
  + `latest.json`, tmp+rename, ротация `bk.keep` (дефолт 10).
- **Расписание:** `bk.period_days` (дефолт 7; unix-время, не millis —
  урок переполнения 49 суток). Первый съём — через 10 мин после старта.
  Внепланово: ~5 мин после `CFG_CHANGED` в парке (`bk.on_change`).
- **Стражи:** нет достоверного времени — плановый съём молчит; 401 от
  устройства — хост блокируется до смены `bk.admin_pin` (мастер не имеет
  права быть источником rate-limiter блокировки админки!); SD нет —
  тихая деградация; `old_fw` для устройств без ядра 5.8.5.
- **ПАЗ:** новая проверка `hm.bk` (Warning при беде хоста).
- **Панель:** новая профильная вкладка **💾 Бэкапы** (между Журналом и
  Настройками): статусы хостов, «Снять сейчас», список снимков,
  «Развернуть» (с подтверждением — устройство перезагрузится).
- **Должок закрыт:** дубль ModuleId 0x1104 — JournalService → **0x1106**
  (комментарии в BridgeService/WeatherMirror обновлены).
- Группа конфига **«Бэкапы»** (`bk.*`) — в конце схемы, живые поля
  (CFG_NONE): вкладка ⚙️ Настройки.

## Сборка и прошивка

Мастер: чистая сборка (правило 20), fqbn как обычно; контрольный размер
у нас: **1110032 Б** (Sketch uses), globals 99293 Б. ФС пересобрать
обязательно (index.html изменился):

```
mklittlefs -c data -p 256 -b 4096 -s 0x360000 littlefs_hm.bin
```

Прошивка парой: `0x10000` прошивка + `0xC90000` ФС. NVS не трогаем.

**Устройства парка (замок/шлюз) тоже надо перевести на 5.8.5** — иначе
мастер честно покажет `old_fw` (export появился в 5.8.5). Их исходники
не менялись — достаточно пересборки на новом ядре.

## Перед первым съёмом

1. В ⚙️ Настройки → «Бэкапы»: проверить `bk.hosts` (дефолт
   10.146.75.53,10.146.75.55) и **задать `bk.admin_pin`** — единый пароль
   администратора устройств парка (поле секретное, NVS).
2. Если пароли админов на устройствах РАЗЛИЧАЮТСЯ — скажите: сделаем
   карту ip→пароль (в 0.6.0 принят единый, как вероятная практика контура).

## Приёмка (предложение)

1. Вкладка 💾 Бэкапы: хосты видны, статусы честные.
2. Через ~10 мин после старта (или «Снять сейчас») — снимки на SD,
   в списке файлы, `latest.json` свежий.
3. Правка поля на замке → через ~5 мин внеплановый снимок.
4. Развернуть снимок замка обратно на замок → ребут, конфиг тот же.
5. ПАЗ: `hm.bk` ok; при выключенном устройстве — Warning с `ip:offline`.
6. SD вытащить/вставить — мастер не падает, съём честно молчит/вернулся.

## Фикс по приёмке (05.09.2026)

**Найдено владельцем:** внеплановый снимок по CFG_CHANGED не запускался.
Причина: `CFG_EVENT_CHANGED` добавлен в `mirrorName()`, но НЕ в список
подписки `MIRRORED[]` — событие не доходило до MqttTransport (имя без
подписки — мёртвый код). Исправлено в `MqttTransport.cpp` (единственный
изменённый файл, достаточно пересборки). Урок записан в коде: имя и
подписка — пара, проверять обе стороны.
Контрольная сборка мастера: 1110048 Б (Sketch uses).
**Важно:** фикс нужен на стороне УСТРОЙСТВ (замок/шлюз публикуют
CFG_CHANGED) — пересобрать и прошить весь парк на 5.8.5-fix.
Повторная проверка приёмки п.3: правка поля на замке → ≤6 мин снимок.

# История документации

Этот каталог сохраняет прежние документы для прослеживаемости архитектуры и решений.

**Содержимое каталога не является актуальным руководством по МикроОС 5.9.9.** Текущее состояние находится в [ПАСПОРТЕ](../ПАСПОРТ.md) и связанных с ним действующих документах.

## Документы базы 5.0

- `МикроОС_5.0_базовая_архитектура.md`;
- `МикроОС_5.0_веб-интерфейс.md`;
- `МикроОС_5.0_дорожная_карта_кондиций.md`;
- `МикроОС_5.0_руководство_автора_профилей.md`;
- `МикроОС_5.0_справочник_платформы.md`.

Файлы сохранены без содержательной переработки. Их названия и формулировки относятся к прежней базе. Наличие в них будущих этапов, старых лимитов или нереализованных концепций не описывает текущее состояние.

## Контракт завершённого этапа

- `Технический_контракт_M3.4a_пассивный_реестр_флота.md` — исходный технический контракт реализованного и закрытого M3.4a.

Фактическая реализация и результат приёмки зафиксированы в [итоговой ноте M3.4a](../ноты/Нота_M3.4a_home_master_0.9.11_закрытие.md).

## Правила использования

- Не использовать историческую дорожную карту как матрицу текущих версий.
- Не считать упомянутую функцию реализованной без подтверждения в исходниках или действующей документации.
- Не удалять историю только из-за устаревания.
- При обнаружении расхождения актуализировать действующий документ и сохранять исторический контекст.

Сетевые настройки

Основной режим — DHCP (сетевая политика 5.5.2); без DHCP-сервера — статика из полей ниже. Монитор деградации пингует шлюз по факту, либо net.probe_host, если задан. Фактическое состояние линка — на вкладке «📊 Статус».

Клиент вышестоящего брокера, встроенный брокер и мост M2 — здесь; сеть отделена (вкладка «🌐 Сеть»). Часть полей применяется после перезагрузки.

Журнал парка (SD)

ВремяИсточникТопикСобытие

Чтение потоковое: страница ≤100 строк, листание курсором — сегмент целиком в память не поднимается. Усечённые записи помечены бейджем cut (тело длиннее бюджета строки, обрезано при записи). Строки с недостоверным временем (ts=0, время ещё не синхронизировано) показываются с «—» и в фильтр по периоду не входят — честно.

Прочие настройки

Схема приходит с устройства. Секретные поля write-only: устройство никогда не отдаёт их значения. Критичные поля применяются после перезагрузки.

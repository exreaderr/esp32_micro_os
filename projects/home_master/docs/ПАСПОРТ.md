# ПАСПОРТ ДОСТАВКИ — home_master 0.6.1 «OTA-зеркало» (05.09.2026)

## Что это
Логическое продолжение M3.3 (одобрено владельцем: «можно проверить М3.3 и
логически продолжить ОТА зеркало»). Замыкается цепочка самодостаточности:
**и прошивка, и бэкап — на мастере**. Адрес HA устройствам парка больше
не нужен ни для чего.

## Как устроено (ядро НЕ тронуто, остаётся 5.8.5)
UpdateService устройств строит URL манифеста из СВОЕГО mqtt.host:
`http://<mqtt.host>:8123/<sys.ota_path>/<hostname>/version.json`.
У устройств парка mqtt.host УЖЕ = мастер (.54), порт 8123 зашит в ядре —
они и так спрашивают мастера. Поэтому мастер:

1. **Зеркалирует** (новый модуль OtaMirrorService, ID 0x1108): раз в
   `otam.period_h` (по умолчанию 6 ч) опрашивает HA (свой mqtt.host =
   10.146.75.5) по каждому hostname из `otam.hosts`, скачивает
   version.json + firmware.bin + littlefs.bin на SD в `/ota/<hostname>/`.
   Порядок коммита: бинари в *.tmp → проверка md5 из манифеста
   (fw_md5/fs_md5) → rename → манифест ПОСЛЕДНИМ. Обрыв питания посреди
   скачивания оставляет старую целостную пару.
2. **Раздаёт**: второй WebServer на :8123 отдаёт РОВНО whitelist
   `/local/ota/<host>/(version.json|firmware.bin|littlefs.bin)` с SD.
   Без авторизации (прошивка — не секрет; устройства токенов не шлют),
   read-only, страж от "..", хосты — только из `otam.hosts`.

**Смена конфига устройств НЕ требуется.** Мастер сам себя не зеркалирует
(его mqtt.host = HA — обновляется напрямую).

## Сборка
- Контрольная: **1120544 B** (85% из 1310720), RAM 31% (223339 B свободно).
  Чистая сборка (первый прогон с --clean). MD5 владельца ≠ песочнице
  (пути сборки) — контроль по размерам + своя сборка, как договорились.
- Прошивка и ФС шьются ПАРОЙ (панель менялась — карточка зеркала).

## Протокол приёмки
1. **Прошить** мастер 0.6.1 (fw+fs парой). Вкладка «Бэкапы» → секция
   «OTA-зеркало»: хосты из otam.hosts, статус «ещё не снято».
2. **Первый опрос**: через ~2 мин после boot (или кнопка «Проверить
   сейчас») — у хостов появляется версия, размеры fw/fs, зелёный бейдж.
   На SD: /ota/smart_lock/{version.json,firmware.bin,littlefs.bin}.
3. **Раздача**: браузер → `http://10.146.75.54:8123/local/ota/smart_lock/version.json`
   → JSON манифеста (значит, и устройство его получит).
4. **Обновление устройства с мастера**: на замке OTA → «Проверить» —
   манифест приходит с мастера, обновление проходит без WAN и без адреса
   HA в конфиге замка. (Если версия на HA == текущей на замке, замок
   честно скажет «обновлений нет» — это тоже подтверждение канала.)
5. **Новая версия на HA** → зеркало подтянулось ≤ 1 периода опроса
   (6 ч) или сразу по «Проверить сейчас»; версия в карточке сменилась.
6. **HA выключен** → ранее снятое зеркало продолжает раздаваться:
   устройство обновляется с мастера без HA и без WAN. В карточке —
   ошибка опроса (warn), ПАЗ hm.ota молчит (зеркало живо).
7. **ПАЗ**: hm.ota зелёный, когда зеркала собраны; warning — если зеркало
   хоста ни разу не собрано и есть ошибка.

## Границы и допущения
- HA должен по-прежнему хостить /local/ota/<hostname>/ (куда Build Master
  публикует сборки) — зеркало оттуда и снимается.
- test_rig в otam.hosts по умолчанию нет — добавить при необходимости.
- Ошибка опроса при живом зеркале — не беда (warn в карточке, ПАЗ молчит);
  беда = зеркало ни разу не собрано.
- Раздача :8123 открыта без авторизации внутри контура (прошивка — не
  секрет; решение владельца 04.09 покрывает класс хранения).

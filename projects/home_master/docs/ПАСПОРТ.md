# Комплект: home_master 0.6.4 — самопроверка бэкапа в момент цикла

**Ядро:** МикроОС 5.8.6 (без изменений — замок и шлюз НЕ трогаем).
**Профиль:** home_master 0.6.3 → **0.6.4**. BackupService 0.2.1-m34 → **0.2.2-m35**.

## Что случилось в приёмке (урок 0.6.3-пр1)

1. OTA с мастера у шлюза рвался: скачивание ФС доходило до ~51% и падало
   с `stall_timeout`; с верхнего брокера — штатно.
2. Лог мастера: повторяющиеся `task_wdt`-ребуты, `last tick: BackupService`,
   и в каждой загрузке `bk: 10.146.75.54 вход не удался (offline)`.

**Корень.** Правка 0.6.3 отсекала собственный IP в `reloadHosts()`, но она
бежит при init модуля (~250 мс), а IP по DHCP появляется только к ~3,5 с.
В момент отсечки собственный IP = `0.0.0.0` → .54 просачивался в список
сетевым слотом. Каждый цикл бэкапа мастер пытался войти по HTTP на самого
себя → зависание → TWDT-ребут. А ребут мастера ПОСРЕДИ раздачи прошивки
зеркалом рвал скачивание у шлюза — отсюда `stall_timeout`.

**Цепочка целиком:** бэкап-цикл → вход на самого себя → завис → WDT →
ребут мастера → обрыв OTA-раздачи → stall_timeout у устройства.

## Что исправлено (только BackupService + версия профиля)

1. `runCycleStep()`: проверка «а не я ли это» перенесена В МОМЕНТ ЦИКЛА —
   IP к этому времени уже известен. Собственный IP снимается локально
   через `stepSelf` (в логе: `bk: 10.146.75.54 — это я сам, снимаю локально`).
2. `loginHost()`: страховка — сетевой вход на собственный IP запрещён
   всегда (`self_ip`), независимо от пути, которым хост попал в список.
3. Отсечка в `reloadHosts()` сохранена (работает при поздних перечитываниях,
   когда IP уже есть).

## Как обновляться

1. Раскатать 3 файла из комплекта в клон репозитория.
2. Собрать, прошить мастера **только прошивкой** (ФС не менялась).

## Проверка (критичная точка приёмки)

1. Монитор порта: после «плановый цикл съёма» НЕ должно быть строк
   `10.146.75.54 вход не удался`; вместо этого — «это я сам, снимаю
   локально» (или .54 вообще отсутствует). Ребутов `task_wdt` быть не должно.
2. Аптайм мастера растёт без срывов ≥ 30 минут (ранее ребуты шли
   каждые ~10 минут).
3. Повторить OTA шлюза С МАСТЕРА (прошивка + ФС) — теперь раздача
   не прервётся ребутом. Ожидаем: обе загрузки до 100%, устройство
   встаёт на новую версию.
4. Карточки бэкапов: «🏠 мастер (этот)», .53, .55 — снимки по кнопке
   и по расписанию, как раньше.

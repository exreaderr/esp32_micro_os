# Комплект: home_master 0.6.7 — ручная загрузка OTA + otam.src + host в манифесте

**Ядро:** МикроОС 5.8.6 (без изменений — замок и шлюз НЕ трогаем).
**Профиль:** home_master 0.6.6 → **0.6.7**. OtaMirrorService 0.1.1-om2 → **0.2.0-om3**.

## Что нового (сценарий «соседа», владелец 07.09.2026)

### 1. Ручная загрузка комплекта прошивки в зеркало (вкладка «Бэкапы»)

Карточка «Загрузить обновление вручную»: выбрать устройство, указать
version.json + firmware.bin + littlefs.bin (можно по одному, в любом порядке)
— мастер принимает файлы в staging на SD и «в строй» ставит только ПОЛНЫЙ
СОГЛАСОВАННЫЙ комплект. Проверки против человеческого фактора:

1. **Привязка к устройству:** поле `host` манифеста == выбранному устройству
   (иначе «ОТКЛОНЕНО: комплект для "weather_gate", а выбрано "smart_lock"»);
2. **md5 прошивки и ФС** против fw_md5/fs_md5 манифеста (битые/чужие файлы);
3. **Метка версии:** тег MICROOS|x.y.z|END внутри firmware.bin == version
   манифеста (манифест от одной версии, бинарник от другой).

Отклонённый комплект удаляется из staging целиком, зеркало продолжает
раздавать ПРЕЖНЮЮ целую тройку. Принятая тройка вытесняет старую в
`/ota/<host>/archive/` — «загрузил не то» обратимо.

Приём идёт на порту :8123 с админ-токеном: чтение раздачи для флота — по-
прежнему открытое, ЗАПИСЬ — только по токену. CORS для панели (:80 → :8123)
учтён.

### 2. otam.src — источник-переопределение (группа «OTA-зеркало», живое)

Пусто (по умолчанию) — как раньше, с HA. Задано (напр.
`http://192.168.1.10:8123`) — мастер зеркалирует с этого адреса: сценарий
«просто компьютер с веб-сервером» без HA вообще. Структура путей та же:
`/local/ota/<хост>/`.

### 3. Build Master: поле "host" в version.json

`conveyor/build_ota.sh` теперь пишет в манифест `"host": "<имя папки
зеркала>"` — это и есть подпись привязки для проверки №1. Старые манифесты
без host мастер принимает (проверка №1 просто не срабатывает), но все новые
релизы будут подписаны.

## Как обновляться

1. Раскатать файлы в клон репозитория (структура сохранена) + build_ota.sh
   в conveyor на компьютере сборки.
2. Менялись и прошивка, и ФС — **шьём ПАРОЙ** (прошивка + LittleFS).

## Проверка

1. Вкладка «Бэкапы»: появилась карточка «OTA-зеркало парка» (она пропадала —
   восстановлена) и «Загрузить обновление вручную».
2. Загрузить тройку smart_lock (из ~/Arduino/ota/smart_lock): вердикт
   «ПРИНЯТО: версия …», в карточке зеркала версия/размеры обновились.
3. Контрпроверка: ту же тройку загрузить, выбрав weather_gate →
   «ОТКЛОНЕНО: комплект для "smart_lock"…» (сработает, когда манифест со
   свежим полем host; на старом манифесте — отклонит по md5/версии, если
   файлы перепутаны).
4. Загрузить заведомо битый файл (обрезать firmware.bin) → «ОТКЛОНЕНО: md5…».
5. Штатный путь не сломан: «Проверить сейчас» в зеркале — опрос HA,
   устройство обновляется с мастера.

## Ядро 5.8.9 — читальный снимок проверок ПАЗ

HealthMonitor: публичные read-only акцессоры `checkCount()`,
`checkNameAt(i)`, `checkStatusAt(i)`, `checkMsgAt(i)`,
`checkLastRunAt(i)` — внешние индикаторы (LED/OLED) отображают ПАЗ,
не вмешиваясь в механизм. Чисто аддитивно, поведение ядра не менялось.

## Профиль home_master 0.7.0 — M5

### StatusLedModule (0x1109) — 4 пикселя WS2812 = лицо ПАЗ
- GPIO21, питание 3.3V (порог data 2.31V — чисто по спецификации),
  резистор ~470 Ом на data.
- Маппинг пикселей В КОНФИГЕ: `led.map` = `hm.sd,hm.bk,hm.ota,hm.fleet`.
- Цвета: зелёный Ok / жёлтый Warning / красный Critical / синий пульс —
  проверка ещё не бежала («нет данных»); погашен — `led.enabled=0`.
- Конфиг (группа «Статус-LED»): led.enabled (умолч. **false**), led.pin
  (21), led.count (4), led.bright (15%), led.map.

### PanelDisplayModule (0x110A) — экран по требованию
- OLED SSD1306 128×64 на I2C-шине платы (16/17 — та же шина, что DS3231;
  адрес 0x3C против 0x68 RTC).
- Экран ВСЕГДА погашен; будит любая кнопка; гашение по `oled.timeout`
  (умолч. 30 с). Кнопки +/−/ОК на GPIO15/18/2 (INPUT_PULLUP, активный
  низ, антидребезг 40 мс, длинное ОК ≥1.5 с).
- Меню: список проверок ПАЗ (человеческие имена, зеркало CHK_NAME
  веб-панели), ОК — детали (статус, сообщение, возраст прогона).
- **View-only первый этап**; длинное ОК — слот действий (пока «ДЕЙСТВИЙ
  НЕТ», архитектура второго этапа заложена).
- Кириллица — свой мини-шрифт 5×7 (CyrFont5x7.h, 165 байт, строчные →
  прописные, Ё≈Е).
- Конфиг (группа «Экран»): oled.enabled (умолч. **false**), oled.addr
  (60), oled.timeout (30), btn.plus/minus/ok (15/18/2).

### Распиновка (утверждена 08.09.2026)
WS2812 data → GPIO21 · OLED SDA → GPIO17 · SCL → GPIO16 ·
кнопки +/−/ОК → GPIO15/18/2 (на GND) · питание ленты 3.3V · OLED 3V3.
Ловушки учтены: GPIO33–37 заняты OPI PSRAM, страппинг 0/3/45/46 обойдён,
W5500 (9–14) и SD (4–7) не тронуты.

## Приёмка

1. Мастер — вручную, fw+FS парой (ядро затронуто, мастер первым).
2. Замок — OTA с мастера (кит 5.8.9, профиль 0.5.15 без изменений).
3. Шлюз — уведомление ветке (ядро аддитивное, адаптация формальная).
4. Железо M5 на макетке: `led.enabled=1` → пиксели оживают;
   `oled.enabled=1` → кнопка будит экран, листаем ПАЗ.
5. Без железа (оба enabled=0) — мастер работает как прежде
   (проверка закона самодостаточности).

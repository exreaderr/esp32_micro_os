# Прошивка контроллера СКУД smart_lock (МикроОС 5.0)

## Состав комплекта

```
arduino/
├── libraries/MicroOS/          — библиотека ядра (скопировать в ~/Arduino/libraries/)
├── smart_lock/                 — проект Arduino IDE (открыть smart_lock.ino)
│   ├── smart_lock.ino          — точка входа (2 строки запуска)
│   ├── src/                    — профиль СКУД (18 файлов)
│   └── data/web/lock.html      — веб-панель (загружается в LittleFS)
└── firmware/                   — готовые бинарники (если не хотите собирать)
    ├── smart_lock.ino.merged.bin    — ПОЛНЫЙ образ 4 МБ (ядро+профиль+загрузчик)
    ├── smart_lock_littlefs.bin      — образ LittleFS с веб-панелью (0x290000)
    └── smart_lock.ino.bin, .bootloader.bin, .partitions.bin, .elf, .map
```

## Вариант А — Arduino IDE (рекомендуется)

1. Скопируйте `libraries/MicroOS` в `~/Arduino/libraries/` (Linux)
   или `Документы/Arduino/libraries/` (Windows).
2. Откройте `smart_lock/smart_lock.ino`. Плата: **ESP32 Dev Module**
   (WT32-ETH01 — полный аналог по распиновке; ядро esp32:esp32 3.3.11).
3. **Скетч → Загрузить** — прошивка ядра с профилем.
4. Веб-панель: инструмент **«ESP32 LittleFS Data Upload»** (плагин IDE 1.x)
   или команда ниже — загружает содержимое `smart_lock/data/`.

## Вариант Б — arduino-cli

```bash
# Прошивка (библиотека уже видна через --libraries или установлена)
arduino-cli compile --fqbn esp32:esp32:esp32 --libraries ./libraries ./smart_lock
arduino-cli upload  --fqbn esp32:esp32:esp32 -p /dev/ttyUSB0 ./smart_lock

# Веб-панель в LittleFS (mklittlefs и esptool — из пакета esp32)
mklittlefs -c smart_lock/data -p 256 -b 4096 -s 0x160000 littlefs.bin
esptool --chip esp32 --port /dev/ttyUSB0 --baud 460800 write_flash 0x290000 littlefs.bin
```

## Вариант В — готовые бинарники (без сборки)

```bash
# Полная прошивка одним образом (загрузчик + ядро + профиль):
esptool --chip esp32 --port /dev/ttyUSB0 --baud 460800 write_flash 0x0 firmware/smart_lock.ino.merged.bin
# Веб-панель:
esptool --chip esp32 --port /dev/ttyUSB0 --baud 460800 write_flash 0x290000 firmware/smart_lock_littlefs.bin
```

## Первый запуск

1. Устройство поднимет Ethernet (DHCP); IP — в журнале Serial (115200)
   или на странице роутера. Публичная страница: `http://<ip>/`.
2. **/admin** — первичная настройка (провижионинг): задайте ПИН администратора,
   сеть/MQTT/время. ПИН жильца — поле `lock.user_pin` (группа «Доступ по вебу»).
3. **/web/lock.html** — панель СКУД (вход по ПИНу админа или жильца).
4. Поднесите **первую карту** к считывателю — она станет мастер-ключом.
   Дальше мастер-ключ циклит режимы: Обычный → Запись карт → Триггер.
5. Безопасный режим (Safe Mode): кнопка EXIT (GPIO14) при старте — как в v2.5.0.

## Совместимость с v2.5.0

- `users.json` — тот же формат: база карт с монолита подхватится как есть.
- NVS-зеркало `db_backup/db_raw` — то же, что в монолите.
- Пины — те же (Wiegand 4/2, реле 15, геркон 39, EXIT 14, DFPlayer 17/5/36).
- Веб-панель: дизайн v2.5.0, эндпоинты — МикроОС 5.0 (карта в справочнике).

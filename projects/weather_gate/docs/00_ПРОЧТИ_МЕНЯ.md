# 00. ПРОЧТИ МЕНЯ — пакет агента ветки weather_gate

Пакет собран ядерной веткой 16.08.2026, ядро **5.8.0**. Это полный
комплект для холодного старта параллельной ветки разработки профиля
**weather_gate** (шлюз погодной станции Fine Offset WS1080 @915 МГц на
WT32-ETH01 + DS3231 + BME280 + CC1101 receive-only).

## Порядок чтения (обязательный)

1. `01_брифинг_weather_gate.md` — ветка целиком: философия, аппаратура,
   архитектура данных, стадии W1–W5, ворота качества. **Главный документ.**
2. `06_уровень_кондиций.md` — что в проекте считается «качеством»:
   числа, ворота, культура уроков. Промышленная дисциплина, не DIY.
3. `02_руководство_автора_профилей.md` — как пишется профиль (методика).
4. `03_базовая_архитектура.md` — ядро: фазы, сервисы, контракты.
5. `04_справочник_платформы.md` — платы, пины, разметка, сборка.
6. `05_концепция_home_master.md` — мастер контура (брокер M1, мост M2,
   журнал M3): куда упирается телеметрия и хранение рядов.
7. `08_веб-интерфейс.md` — панели: uPlot, PWA, правила sw.js.
8. `07_дорожная_карта_кондиций.md` — журнал релизов 5.0 → 5.8.0:
   все уроки и принятые бенчи. Читать последним, как «летопись».

## Код и тесты

- `MicroOS/` — библиотека 5.8.0 целиком, **код-истина**. Эталон профиля —
  `MicroOS/projects/smart_lock/`, второй живой пример — `home_master/`,
  скелет-старт ветки — `test_rig/`.
- `host/` — хост-тесты (ворота качества №1): 43351 assert, 0 FAIL.
  Прогон до любой прошивки: `cd host && ./run_tests.sh`.

## Прежде чем писать код

Подтверди владельцу понимание и запроси недостающее (список — в §10
брифинга): адрес BME280, высота установки датчика, IP/hostname шлюза,
расположение станции. Затем — стадия W1 по брифингу.

Расхождение документа с кодом = правда в коде + доклад в ядерную ветку.
«Торопиться — не наш метод».

# W6 — Статус-LED шлюза (WS2812): дизайн-нота

Дата: 09.09.2026
Статус: ПРОЕКТ — ожидает решений владельца по железу
Основание: ядро 5.8.9 (снимок проверок ПАЗ) + решение владельца 09.09.2026
(«RGB-светодиодами индицировать статус служб для автономности»);
OLED — избыточно (согласовано устно, не делаем).

## 1. Что даёт ядро и что уже есть во флоте

- Ядро 5.8.9: читальный снимок проверок ПАЗ — `checkCount()`,
  `checkNameAt(i)`, `checkStatusAt(i)`, `checkMsgAt(i)`, `checkLastRunAt(i)`.
  Модуль ПАЗ не трогаем — только отображаем.
- Эталон: `StatusLedModule` мастера 0.7.0+ (профильный код, НЕ ядерный):
  4 пикселя WS2812, маппинг «пиксель → проверка» В КОНФИГЕ, цвета
  зелёный/жёлтый/красный/синий пульс («нет данных»), мастер-выключатель
  `led.enabled` (нет ленты = устройство работает полной программой —
  закон самодостаточности). Статусы уже отфильтрованы подтверждением
  переходов ядра 5.8.7 — пиксель не дёргается.
- Adafruit NeoPixel 1.15.5 уже стоит в среде сборки (для мастера).

## 2. План шлюза (перенос эталона, адаптация)

- Модуль `WgStatusLedModule` — порт StatusLedModule в профиль шлюза,
  ModuleId из нашего диапазона (приложение = 0x1000; предложение 0x1001).
- Конфиг (группа «Статус-LED», CFG_CRITICAL — смена через ребут):
  - `led.enabled`  BOOL  false — по умолчанию ВЫКЛ (железа может не быть);
  - `led.pin`      UINT  (см. §3 — решает владелец);
  - `led.count`    UINT  3 (1..8);
  - `led.bright`   UINT  15 (1..100 %);
  - `led.map`      STRING "wg.radio,wg.bme280,wg.storm".
- Логика цветов — 1:1 эталон: Ok=зелёный, Warning=жёлтый, Critical=красный,
  не бежала = синий медленный пульс, led.enabled=0 = всё погашено.
- Индикация по снимку ПАЗ: три наших проверки покрывают главное —
  датчик (BME280), эфир (радиоканал), шторм-флаг. Общий статус сети
  ядерных проверок на шлюзе нет — при желании четвёртый пиксель можно
  повесить на будущую проверку (не сейчас).

## 3. Железо — открытые вопросы (пин-план 17.08.2026)

Свободных ног у WT32-ETH01 мало. Кандидаты на data WS2812:

| Пин | Статус в пин-плане | Оценка |
|---|---|---|
| GPIO2  | «LED профиля» (одиночный) | Страппинг: при прошивке держать LOW. WS2812 через ~470 Ом на data обычно не мешает, но если одиночный LED распаян — конфликт |
| GPIO5  | Резерв (после прозвонки эрраты IO5/IO35) | Лучший кандидат, если эррата закрыта и нога реально свободна |
| GPIO12 | Резерв, «никогда не CS» | HIGH при буте = нет загрузки — под WS2812 рискованно, НЕ рекомендуем |

Вопросы владельцу:
1. Есть ли в наличии лента/модуль WS2812 (сколько пикселей)?
2. Распаян ли одиночный LED на GPIO2? Если нет — можно отдать GPIO2 ленте.
3. Эррата шелкографии IO5/IO35 — прозвонка завершена? GPIO5 свободен?
4. Питание ленты: 3.3V (как у мастера, до ~8 пикселей при 15% — хватит)
   или 5V (тогда нужен сдвиг уровня data — усложнение, не надо).
